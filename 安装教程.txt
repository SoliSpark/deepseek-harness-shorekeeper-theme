============================================================
一、这是什么
============================================================
这是一个给 DSH（DeepSeek Harness）使用的“主题插件”，装上之后：

· 启动 DSH 时，先播放守岸人开场动画：
  线稿一笔一笔画出闭眼的画面 → 睁眼 → DeepSeek 字样与「欢迎回来，漂泊者」
  → 黑海岸标识拼合 → 画面像粒子一样消散，再聚合成聊天界面。
· 聊天界面的背景使用同一段动画做成的无缝循环（6–10 秒），
  也可以换成你自己的图片或视频。
· 左侧栏多一个「守岸人主题」入口，可以调节界面透明度、背景压暗、背景模糊，
  也可以重播启动动画。
· 所有设置都会自动保存，下次打开还在。

插件完全在本机运行，不需要联网，不需要额外的账号或 Key，
启动影片、线稿、标识都已经打包在插件里。

============================================================
二、安装到哪里
============================================================
1) 插件本体：
   建议把整个文件夹放到一个固定位置，例如：
     D:\DeepSeek Harness\plugins\deepseek-harness-shorekeeper-theme
   放好之后不要再移动。移动了要重新执行下面的安装命令。

2) 安装目标（DSH 的 desktop 配置）：
     C:\Users\<你的用户名>\.dsh\profiles\desktop
   这个目录由 DSH 自己管理，里面有一个 package.json 记录已安装的插件。

============================================================
三、安装步骤（只需要做一次）
============================================================
第 1 步：把整个文件夹放到上面建议的位置（路径可以自己改，但不要有特殊符号）。

第 2 步：打开 PowerShell，执行下面这一行（路径按你的实际位置改）：

  & "D:\DeepSeek Harness\resources\runtime\cli\bin\dsh.cmd" plugin --profile desktop add "link:D:\DeepSeek Harness\plugins\deepseek-harness-shorekeeper-theme"

  如果提示找不到 dsh.cmd，就把引号里的路径换成你电脑上 DSH 的安装位置。

第 3 步：确认插件被启用。
  用记事本打开：
     C:\Users\<你的用户名>\.dsh\profiles\desktop\package.json
  找到 "dsh" → "profile" → "bundles" 这一段，里面应该有：
     "@local/dsh-shorekeeper-startup"
  如果没有，手动加一行（注意前后的逗号），保存。

第 4 步：完全退出 DSH。
  只关窗口不够，请从系统托盘退出（或任务管理器结束 DSH），然后再打开。

============================================================
四、怎么使用
============================================================
· 启动动画：每次打开 DSH 自动播放；按 ESC、点击画面或点「跳过」可以立刻结束。
· 打开主题设置：左侧栏点击「守岸人主题」。
  - 背景：启动动画 / 图片 / 视频（支持拖入文件，文件只保存在本机）
  - 显示：界面透明度、背景压暗、背景模糊
  - 启动动画：开关“每次启动播放”，或手动“重播启动动画”
· 关闭主题：设置页里的总开关关掉，就会恢复 DSH 原本的外观。
· 想临时看聊天：按 ESC 跳过动画即可。

小提示：
· 第一次启动时，动画前面会有一小段纯黑画面（这是插件的“预启动遮罩”，
  用来挡住 DSH 自己的加载界面），属于正常现象。
· 右上角的最小化/最大化/关闭按钮是 Windows 原生按钮，网页层盖不住，
  动画播放时它们仍会显示在最上层。

============================================================
五、卸载
============================================================
1) 打开 PowerShell 执行：
   & "D:\DeepSeek Harness\resources\runtime\cli\bin\dsh.cmd" plugin --profile desktop remove @local/dsh-shorekeeper-startup

2) 打开 C:\Users\<你的用户名>\.dsh\profiles\desktop\package.json，
   把 bundles 里的 "@local/dsh-shorekeeper-startup" 删掉。

3) 重启 DSH，之后就可以删除插件文件夹了。

============================================================
六、常见问题
============================================================
· 打开后还是原来的界面？
  说明插件没加载：检查 package.json 的 bundles 里有没有这个插件；
  再确认是不是从托盘完全退出后重启的。

· 左侧栏没有「守岸人主题」？
  先执行上面的 remove 命令，再按新路径重新 add 一次。

· 启动动画期间看不到工作台？
  这是舞台幕布，用来避免聊天界面在动画前后闪现；片尾或按 ESC 后会淡出。

· 想换素材重新生成？
  需要 Node.js。替换 assets 里的影片/标识后，在插件目录执行：
     node build.mjs
  就会重新生成 client.js。

· 移动了插件文件夹？
  旧的链接会失效：先 remove，再按新路径 add。

· 动画速度想调？
  需要改 client.template.js 顶部的 RATE（整体速度）与 CUT_AT / OUT_AT
  （睁眼与退场时间），改完重新 build。普通使用不需要动。
