守岸人伴侣 使用说明
版本：1.2.2

========================================
一、它是什么
========================================
守岸人伴侣是主题附带的交互模块，包含：
- 桌宠：可拖动、点击说话、右键菜单；
- 聊天终端：三栏界面，流式对话、工具调用、token 统计；
- 语音：基于本地 GPT-SoVITS 的 TTS，可自动朗读，也可用系统音色；
- 音乐：「频率监测」播放器，默认曲目、播放清单、波形可视化；
- 记忆与角色卡：人设、对话记录、心情/好感度状态。

========================================
二、运行原理
========================================
1. 浏览器端（client.js）
   - 通过 DSH 的 shell.overlay 槽位注册桌宠与终端面板；
   - 桌宠点击/右键 → 打开终端或语音设置；
   - 终端通过 /shorekeeper/chat 发送消息，接收 NDJSON 流式回复；
   - 语音通过 /shorekeeper/tts 调用 Host 代理，再由 Host 请求本地 GPT-SoVITS；
   - 音乐通过 /shorekeeper/default-track 流式获取默认曲目；导入的本地文件在浏览器内播放。

2. Host 端（index.js）
   - /shorekeeper/chat：把对话交给 DSH 的模型，按行流式返回；
   - /shorekeeper/tts：把文本转发给 GPT-SoVITS，返回音频；
   - /shorekeeper/voice-status：检测 9880 端口是否在线；
   - /shorekeeper/voice-assets：扫描权重与参考音频；
   - /shorekeeper/voice-config、/pick-file、/open-folder、/voice-start：音色配置与启动；
   - /shorekeeper/default-track：默认音乐（支持 Range，可拖动进度）；
   - /shorekeeper/uninstall：设置页「卸载主题」调用。

3. 语音链路
   DSH 终端 → Host /tts → GPT-SoVITS api_v2.py（127.0.0.1:9880）→ 返回 wav → 浏览器播放。
   未连接引擎时，可在语音设置中改用系统音色（speechSynthesis）。

========================================
三、桌宠
========================================
- 左键单击：随机说一句话（气泡显示在右侧）；
- 拖动：移动位置，位置会记住；
- 右键：打开菜单（打开终端、语音设置、重置位置、连接/断开伴侣）；
- 关闭「连接守岸人」后桌宠消失，聊天记录与设置会被清除。

========================================
四、终端
========================================
- 右键桌宠 → 打开终端，或在设置页点「打开聊天」；
- 输入框回车发送，Shift+Enter 换行；
- 回复为流式输出，可随时停止；
- 右侧面板：频率监测（音乐）、星海档案（人设/状态）；
- 顶部显示 token 用量；
- 关闭终端不会停止音乐，只停止界面渲染。

========================================
五、语音（TTS）使用
========================================
前提：
1. 本机已安装 GPT-SoVITS（v2Pro）；
2. 已准备好权重与 3–10 秒参考音频；
3. voicepack.json 中的路径正确，或安装后在语音设置中手动选择；
4. 启动语音 API（可用包内/工作区的「启动语音API.bat」，或手动运行 api_v2.py）。

步骤：
1. 右键桌宠 → 语音设置；
2. 「环境」应显示已检测到；
3. 打开「使用自定义音色」，分别选择 GPT 权重、SoVITS 权重、参考音频；
4. 点「启动」启动 API，等待「引擎」显示已连接（约 15 秒轮询一次）；
5. 打开「自动朗读」，之后：
   - 终端回复会自动朗读；
   - 桌宠气泡也会朗读（快速连点只读最后一句）。

其它：
- 每条回复旁的扬声器按钮可单独朗读；
- 可调语速、音量；
- 引擎不可用时，可打开「使用系统音色」作为兜底；
- 两个开关都关闭时，会提示先选择音色。

注意事项：
- API 窗口必须保持运行，关闭后语音不可用；
- 参考音频过短/过长会被 API 拒绝；
- 首次合成较慢，之后会快很多；
- 语音文件不会上传，只在本机处理。

========================================
六、音乐
========================================
- 默认曲目固定为「漂泊的终点」，不可删除；
- 「导入音乐」可追加本地音频；
- 播放清单中：默认曲目灰色带「默认」标记；其它曲目可点 × 删除；
- 波形为实时频谱（Web Audio），关闭终端后停止绘制以节省资源；
- 关闭终端音乐继续播放；
- 只有在终端内暂停、退出 DSH、或停用伴侣时才会停止。

========================================
七、记忆与角色
========================================
- 人设与对话保存在本机 localStorage；
- 可在「星海档案」查看/编辑角色卡；
- 清除聊天记录会同时清除伴侣的本地记忆；
- 断开伴侣会清除聊天记录、音色与桌宠设置。

========================================
八、注意事项
========================================
1. 语音依赖本地 GPT-SoVITS，未安装时只能用系统音色；
2. voicepack.json 是绝对路径，换机器需重新配置；
3. 终端与桌宠会占用一定内存，低配机器可关闭伴侣；
4. 不要同时运行多个 DSH 实例操作同一份聊天记录；
5. 卸载请用设置页「卸载主题」或命令行，避免残留注册；
6. 升级后需要完全重启 DSH。

========================================
九、常见问题
========================================
Q：桌宠不出现？
A：确认设置页「连接守岸人」已开启；启动动画完全结束后约 0.4 秒出现。

Q：语音没有声音？
A：检查 9880 端口是否在线、是否选择了三个音色文件、自动朗读是否开启；
   也可先用「使用系统音色」验证播放链路。

Q：音乐无法播放？
A：确认 DSH 已重启（Host 路由需要重启后生效）；默认曲目走 /shorekeeper/default-track。

Q：卸载后还有残留？
A：完全退出 DSH 再启动；如仍有入口，检查 profile 的 package.json 是否已移除该 bundle。
